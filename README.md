## Security and transparency

The BLL token is a standard fixed-supply OpenZeppelin ERC-20. The deployed token contract does not provide post-deployment minting. An independent third-party smart-contract audit is being pursued; this repository does **not** represent the project as audited until an independent audit is completed.

The presale contract uses OpenZeppelin Ownable, ReentrancyGuard and SafeERC20 components and enforces purchase limits and the sale allocation.
